# Вариант 12. «Файловый обменник»

Сервис приёма файлов с проверкой загрузок. Старый Java-сканер файлов упакован в «толстый» JAR. Go-часть сжимает файлы и логирует операции.

Вы — инженер по безопасности. Перед выводом сервиса в продуктивную среду нужно провести анализ
состава ПО, оценить найденные уязвимости и довести образы до прохождения security gate.
Общий порядок работы описан в [README.md](../../README.md), здесь — только особенности варианта.

## Состав

| Компонент | Каталог | Образ |
|---|---|---|
| Python-сервис | `python-app/` | `lab4/v12-py:before` |
| Go-сервис | `go-app/` | `lab4/v12-go:before` |

## Сборка исходных образов

```bash
cp -r variants/v12 ~/lab4-<фамилия>-v12 && cd ~/lab4-<фамилия>-v12
mkdir -p sbom scans
docker build -t lab4/v12-py:before python-app
docker build -t lab4/v12-go:before go-app
```

## Что нужно сделать

Подробные инструкции и примеры команд — в разделе 2 [методички](../../README.md#2-порядок-выполнения).

- [ ] Скопировать каталог варианта и собрать исходные образы (команды выше).

      по типам; сравнить SBOM исходников и образа; извлечь Go-бинарь и построить SBOM по нему; сравнить слои.
- [ ] **Часть 2.** Просканировать оба SBOM grype, сохранить JSON-отчёты, составить сводку находок.
- [ ] **Часть 3.** Составить топ-10 уязвимостей по RISK для каждого образа, разобрать три уязвимости.
- [ ] **Часть 4.** Исправить `python-app/` и `go-app/`; собрать `lab4/v12-py:after` и `lab4/v12-go:after`

      риск и заполнить `.grype.yaml`.

## Индивидуальные вопросы

Ответы оформите в разделе 6 отчёта. Каждое утверждение подтверждайте командой и её выводом (фрагментом).

1. Где именно в образе находятся Java-библиотеки (путь в образе и путь внутри архива — поле `metadata.virtualPath` в syft-json)? Как syft их обнаружил? Сколько JAR-файлов нашла бы «наивная» инвентаризация `find / -name '*.jar'` внутри контейнера и какие уязвимые библиотеки она бы пропустила?
2. Найдите уязвимость commons-fileupload с уровнем Critical. Что она позволяет сделать и при каком использовании библиотеки? Как бы вы решили, удалять ли сканер из образа?
3. Сравните время, которое прошло с публикации уязвимостей waitress 1.4.3 до сегодняшнего дня. Что говорят EPSS и KEV о том, насколько активно эксплуатируются уязвимости с «возрастом»?
